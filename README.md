# Brain Arena


## Общее описание

**Brain Arena** - программно-алгоритмический комплекс для решения интеллектуальных задач

## Архитектура системы

### Технологический стек
- **Backend**: Django 4.2.7
- **База данных**: SQLite (по умолчанию), MySQL (опционально)
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Дополнительно**: Pillow, django-crispy-forms, python-dotenv

В проекте использованы Bootstrap стили, в том числе подключен Font Awesome 5, который включает в себя набор иконок, SVG и прочий иконочный CSS-инструментарий. Подробнее можно ознакомиться на сайте: https://fontawesome.ru
https://fontawesome.ru/examples/

### Инструкция как добавить новую игру

1. Добавить пустую новую папку с названием игры в gameList.
2. Добавить в папку с названием игры файл-движок engine.py.
3. Добавить .html шаблон для игры в template/games/
4. Перезагрузить систему.
    При каждом запуске Django (старт сервера, перезагрузка и т.д.) система:
    1. Сначала загружает все игры из папки `gamesList` через `load_games()`
    2. Затем автоматически синхронизирует их с базой данных через `sync_games()`    
    3. Если в app.py есть зарегистрированные игры (код), но их нет в БД (запись в БД) - они создаются автоматически
    4. Если игры уже есть в БД - ничего не происходит
	import games.gamesList.НАЗВАНИЕ_ИГРЫ.engine
    5. Примечание: в процессе разработки для удобства разработки в файле loader.py в методе sync_games может быть изменено условие обновления, чтобы не перезагружать систему. При этом следует убедиться, что в игры не вносились изменения через админ-панель, иначе они могут быть перезаписаны в соответствии с исходными файлами .py и .html.
        5.a. Только создает, но не обновляет:
        Game.objects.get_or_create
        5.b. Для разработки с принудительным обновлением:
        Game.objects.update_or_create

## I способ

1. Установите и активируйте виртуальное окружение
    ```bash
    python -m venv env
    source ./env/bin/activate - для Linux
    source ./env/Scripts/activate - для Windows
    ```

2. Установите зависимости
    ```bash
    pip install -r requirements.txt
    ```

3. Выполните миграции
    ```bash
    # foodgram-st/backend
    python manage.py migrate
    ```

4. Создайте суперпользователя:
    ```bash
    python manage.py createsuperuser
    ```

5.  Загрузите статические файлы:
    ```bash
    python manage.py collectstatic
    ```

6. Запустите сервер командой:
    ```bash
    python manage.py runserver
    ```

## Особенности реализации

### Тестовая игра
- Создана для проверки корректной работы статусов игр и их завершения
- Доступные действия:
    win - завершить игру победой
    lose - завершить игру поражением
    surrender - сдаться
- По умолчанию неактивна, используется для тестирования системы администрацией и разработчиками

### Ханойские башни
- Условия победы - все стержни правильной пирамидой на третьем (правом стрежне)
- Data (данные, которые хранит игра. Пример для идеального решения при 2 дисках):
    {"level": 2,
    "pegs": [[], [], [2, 1]],
    "moves": 3,
    "optimal_moves": 3}
- Сложность задается через query-параметры: level=2,3,4,5,6,7,8
- для level=n: n дисков
- Всегда (начальные условия): n дисков на на левом (первом стержне)
- Подсчет оптимальных ходов по формуле: 2^n+1
- Drag & Drop интерфейс
- Валидация правил игры
- Автоматическое решение
- Подсчет оптимальных ходов
- Можно перемещать только верхний диск на стержне
- Нельзя помещать больший диск на меньший
- На пустой стержень можно помещать любой диск

### Быки и коровы
- Сложность через query-параметры: level=repeat, no_repeat
- При создании игры случайным образом генерируется 4-хзначное число
- У пользователя есть поле ввода (только 4 числа) и кнопка "отправить", которая проверяет введенный результат с правильным.
- Под областью создается таблица: номер попытки, введенное пользователем число, угаданные цифры и цифры на правильных местах.
- Игра длится пока пользователь не угадает число
- Конечная статистика содержит число попыток.

### 2048
- Игровое поле 4х4
- За каждый шаг в случайной свободной клетке поля генерируется новая клетка с цифрой 2 или 4. Генерация плиток 2 (90%) / 4 (10%)
- Слияние одинаковых плиток по всем 4 направлениям
- Подсчет текущего счета
- Автоматическое сохранение и обновление лучшего счета пользователя
- Поддержка лидерборда
- Управление через свайп или стрелки клавиатуры

## Использование скрытых комментариев в проекте

При написании html кода для обновлений следует придерживаться правила, что:
<!-- Открытый комментарий --> хуже чем
{% comment %} Скрытый комментарий {% endcomment %}

HTML-комментарий может увидеть пользователь через F12
Django-комментарий полностью удаляется при генерации HTML

Можно писать без {% comment %}  {% endcomment %}, используя короткую версию:
{# Короткий скрытый комментарий#}

## Безопасность для внешних ссылок

Всегда используйте такую конструкцию для внешних сайтов:

<a href="https://другой-сайт.com" target="_blank" rel="noopener noreferrer">
    Внешняя ссылка
</a>

Атрибуты:
- noopener - полностью блокирует доступ к window.opener

- noreferrer - скрывает адрес вашего сайта (Referer header), чтобы злоумышленник не узнал, откуда пришёл пользователь
